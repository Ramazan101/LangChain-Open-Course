# Модуль 00. Подготовка окружения и первый вызов нейросети

> Модуль-«проверка зажигания». Прежде чем строить цепочки и агентов, нужно убедиться, что среда настроена, секретный ключ читается, а запрос к нейросети доходит и возвращается обратно.

---

## 1. Зачем нужен этот модуль

Любая работа с нейросетью начинается с трёх вопросов:

1. Установлены ли библиотеки так, чтобы не сломать систему?
2. Где лежит секретный ключ и не попадёт ли он случайно в интернет?
3. Доходит ли запрос до модели и возвращается ли ответ?

Файлы этого модуля отвечают на все три вопроса за один запуск. Если скрипт напечатал «ЗАПРОС УСПЕШНО ВЫПОЛНЕН!», фундамент готов, и на нём можно строить дальше.

---

## 2. Объяснение для новичка

Представьте, что нейросеть сидит в другом городе. Прийти к ней нельзя, поэтому вы звоните.

| Бытовой образ | Что это в проекте |
| :--- | :--- |
| Эксперт в другом городе | Нейросеть (модель Qwen) |
| Телефонная станция, соединяющая со многими экспертами | Шлюз OpenRouter |
| Ваш личный пароль для станции | Ключ API |
| Записная книжка с паролем, которую никому не показывают | Файл `.env` (его нельзя отправлять на GitHub) |
| Отдельный ящик с инструментами только для одного проекта | Виртуальное окружение `venv` |
| Инструкция эксперту «отвечай коротко и по делу» | Системное сообщение (`SystemMessage`) |
| Сам вопрос | Сообщение человека (`HumanMessage`) |

Почему нужен `venv`: в Manjaro системный Python используется самой системой. Если установить в него свои пакеты, можно что-нибудь сломать, а `pip` вообще откажется работать с ошибкой `externally-managed-environment`. Виртуальное окружение решает проблему: все библиотеки лежат внутри папки проекта.

---

## 3. Объяснение для профи

- `ChatOpenAI` — клиент протокола, совместимого с интерфейсом OpenAI. Подмена `base_url` перенаправляет запросы на OpenRouter, который маршрутизирует их к выбранной модели. Смена поставщика сводится к смене трёх параметров: `model`, `base_url`, `api_key`.
- Суффикс `:free` в названии модели означает бесплатный тариф OpenRouter: действуют лимиты на частоту и число запросов, возможны очереди и ответ с кодом 429.
- `invoke` — синхронный вызов: программа ждёт полного ответа. Для потоковой выдачи есть `stream`, для асинхронной работы — `ainvoke`.
- Ответ — объект `AIMessage`. Кроме текста (`content`) в нём есть `response_metadata` (причина остановки, имя модели) и `usage_metadata` (число токенов на входе и выходе).
- `max_tokens` ограничивает длину ответа, а не запроса.
- Параметры `api_key` и `base_url` (файлы этого модуля) и `openai_api_key` и `openai_api_base` (файлы других модулей) — это две записи одного и того же: вторые являются псевдонимами первых.

## 5. Термины

| Термин | Что это простыми словами | Техническая суть |
| :--- | :--- | :--- |
| `venv` | Личный ящик с библиотеками проекта | Изолированный каталог с собственным интерпретатором и пакетами |
| `pip` | Установщик библиотек | Менеджер пакетов Python |
| `requirements.txt` | Список покупок для проекта | Перечень пакетов с точными версиями; ставится командой `pip install -r requirements.txt` |
| Переменная окружения | Записка, доступная всем программам процесса | Пара «ИМЯ=значение» в окружении процесса |
| `.env` | Файл с секретами | Текстовый файл с парами «ИМЯ=значение», в `.gitignore` |
| `load_dotenv()` | Читалка записной книжки | Ищет `.env` от папки скрипта вверх по каталогам и загружает значения в окружение |
| `os.getenv("ИМЯ")` | Достать значение по имени | Возвращает строку или `None`, если переменной нет |
| Ключ API | Пароль для доступа к модели | Секретная строка, по которой шлюз узнаёт вас и ведёт учёт |
| OpenRouter | Единая точка входа ко многим моделям | Шлюз-агрегатор с интерфейсом, совместимым с OpenAI |
| `ChatOpenAI` | Объект «собеседник-нейросеть» | Класс пакета `langchain-openai` для диалоговых моделей |
| `model` | Какую именно нейросеть звать | Идентификатор вида «автор/название:тариф» |
| `base_url` | Адрес телефонной станции | Базовый адрес API |
| `max_tokens` | Потолок длины ответа | Максимум токенов, которые модель сгенерирует |
| Токен | Кусочек текста размером в слог или короткое слово | Единица, в которой модель читает и пишет текст и в которой считаются лимиты |
| `SystemMessage` | Инструкция «как себя вести» | Сообщение с ролью «система» |
| `HumanMessage` | Вопрос человека | Сообщение с ролью «пользователь» |
| `invoke` | «Позвонить и дождаться ответа» | Единый синхронный метод вызова любого компонента LangChain |
| `AIMessage` | Ответ нейросети | Объект с полями `content`, `response_metadata`, `usage_metadata` |
| LangSmith | «Чёрный ящик самолёта» для запросов | Облачный сервис трассировки, см. раздел 9 |

## 6. Кто что выполняет

| № | Действие | Кто выполняет |
| :--- | :--- | :--- |
| 1 | Записывает ключ в файл `.env` | Вы (разработчик) |
| 2 | Читает `.env` и загружает значения в окружение | `load_dotenv()` |
| 3 | Достаёт ключ из окружения | `os.getenv(...)` |
| 4 | Создаёт клиент модели с адресом шлюза | `ChatOpenAI(...)` |
| 5 | Составляет список сообщений | Вы |
| 6 | Отправляет запрос по сети | `llm.invoke(...)` |
| 7 | Принимает запрос и выбирает нужную модель | OpenRouter |
| 8 | Генерирует текст ответа | Нейросеть |
| 9 | Печатает ответ в терминал | Ваш скрипт (`print`) |

## 7. Схема потока данных

```text
 файл .env          ваш скрипт              OpenRouter              нейросеть
     │                   │                       │                      │
     │  load_dotenv()    │                       │                      │
     ├──────────────────►│                       │                      │
     │                   │ invoke([Система,      │                      │
     │                   │         Человек])     │                      │
     │                   ├──────────────────────►│ выбирает модель      │
     │                   │                       ├─────────────────────►│
     │                   │                       │                      │ генерирует
     │                   │                       │◄─────────────────────┤
     │                   │◄──────────────────────┤                      │
     │                   │ печатает content      │                      │
```

## 8. Разбор кода по частям

| Фрагмент кода | Что происходит |
| :--- | :--- |
| `load_dotenv()` | Загружает секреты из `.env` в окружение процесса |
| `model="qwen/qwen3.8-27b:free"` | Идентификатор модели в каталоге OpenRouter. Если модель переименуют или уберут, будет ошибка «модель не найдена»; актуальные названия смотрите на сайте OpenRouter |
| `api_key=os.getenv("OPENROUTER_API_KEY")` | Ключ берётся из окружения, в коде его нет. Если переменной нет, вернётся `None`, и запрос не пройдёт авторизацию |
| `base_url="https://openrouter.ai/api/v1"` | Адрес шлюза. Без этой строки запрос ушёл бы напрямую к OpenAI |
| `max_tokens=1000` | Ответ не будет длиннее 1000 токенов |
| `messages = [SystemMessage(...), HumanMessage(...)]` | Диалог из двух реплик с ролями |
| `response = llm.invoke(messages)` | Отправка запроса и ожидание ответа |
| `response.content` | Текст ответа. Сам `response` — объект `AIMessage`, а не строка |

## 9. LangSmith: как подключается трассировка

В коде этого модуля LangSmith не вызывается. Трассировка включается снаружи, переменными в файле `.env`:

```ini
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=ваш_ключ_langsmith
LANGSMITH_PROJECT=langchain-open-course
```

Если эти переменные заданы, каждый вызов `invoke` автоматически попадает в личный кабинет на сайте smith.langchain.com: видно входные сообщения, ответ, время и число токенов. Старые имена переменных (`LANGCHAIN_TRACING_V2`, `LANGCHAIN_API_KEY`, `LANGCHAIN_PROJECT`) тоже поддерживаются. Код менять не нужно, и это главное удобство такого подхода.

## 11. Частые ошибки

| Симптом | Причина | Решение |
| :--- | :--- | :--- |
| `ModuleNotFoundError: No module named 'dotenv'` | Окружение не активировано или зависимости не установлены | `source venv/bin/activate`, затем `pip install -r requirements.txt` |
| `error: externally-managed-environment` | Установка пакетов в системный Python Manjaro | Создать окружение: `python -m venv venv`, активировать и ставить пакеты уже в него |
| Ошибка авторизации (код 401) | Ключ пустой, неверный или `.env` не найден | Проверьте, что `.env` лежит в корне проекта, в нём нет лишних пробелов и кавычек |
| Код 429 | Исчерпан лимит бесплатной модели | Подождать или выбрать другую модель |
| «Модель не найдена» (код 404) | Устарело или неверно написано название модели | Сверить название с каталогом OpenRouter |

## 12. Проверь себя

<details>
<summary>1. Зачем ключ вынесен в `.env`, а не записан в код?</summary>

Чтобы он не попал на GitHub. Файл `.env` перечислен в `.gitignore`, и Git его не отслеживает.
</details>

<details>
<summary>2. Что вернёт `os.getenv("OPENROUTER_API_KEY")`, если переменной нет?</summary>

Значение `None`. Запрос уйдёт без ключа и завершится ошибкой авторизации.
</details>

<details>
<summary>3. Чем `response` отличается от `response.content`?</summary>

`response` — объект `AIMessage` с метаданными, `response.content` — только текст ответа.
</details>

<details>
<summary>4. Что изменится, если убрать строку `base_url`?</summary>

Запрос пойдёт напрямую к OpenAI, а ключ OpenRouter там не подойдёт.
</details>

---

## 13. Что запомнить

- Секреты живут в `.env`, а не в коде.
- Все библиотеки ставятся внутрь `venv`.
- Смена модели или поставщика сводится к смене `model`, `base_url` и ключа.
- Ответ модели — объект `AIMessage`, текст лежит в `content`.
