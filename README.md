# Практический курс LangChain & LangGraph

Репозиторий с практическими заданиями, цепочками LCEL, RAG и агентами на LangGraph.

## Структура
- `00_setup/` — проверка окружения и интеграции с LangSmith
- `01_lcel_basics/` — синтаксис LCEL и базовые пайплайны
- `02_tools_and_schemas/` — инструменты и Pydantic-схемы
- `03_rag_vectorstores/` — хранилища векторов и поиск по контексту
- `04_langgraph_agents/` — циклы, стейт и мультиагентные системы
